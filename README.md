
# ⚽ Kernel FC - Sistema da Atlética de ADS (FACAM)

> Plataforma web desenvolvida em PHP para a gestão da Atlética de Análise e Desenvolvimento de Sistemas da FACAM, contando com painel administrativo, personalizador de camisas e galeria de eventos.

🌐 **Acesse o projeto online:** [kernelfc.great-site.net](http://kernelfc.great-site.net)

---

## 📌 Funcionalidades Principais

- 🛡️ **Painel Administrativo (CRUD):** Área restrita para gerenciamento de conteúdos, fotos e solicitações de uniformes.
- 👕 **Personalização de Camisas:** Ferramenta interativa que permite aos alunos personalizar e visualizar camisas da atlética antes do pedido.
- 🖼️ **Galeria de Fotos:** Exibição dinâmica de registros fotográficos dos eventos e jogos da atlética.
- 📱 **Design Responsivo:** Interface adaptada para navegação via dispositivos móveis e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **Back-end:** PHP (Processamento de rotas, sessões e regra de negócio)
- **Banco de Dados:** MySQL (Persistência de dados de usuários, fotos e solicitações)
- **Front-end:** HTML5, CSS3, JavaScript (Manipulação interativa do DOM para o personalizador)
- **Hospedagem:** InfinityFree

---

## 🧠 Conceitos Praticados e Aprendizados

Desenvolver este projeto para uma aplicação do mundo real permitiu consolidar conceitos fundamentais do curso:

1. **Manipulação de Estado e Sessões (PHP):** Autenticação de administradores e controle de acesso ao painel.
2. **Integração com Banco de Dados (CRUD):** Leitura e gravação dinâmica de fotos, dados do formulário e personalizações de uniforme no MySQL.
3. **Lógica de Front-end Interativo (JavaScript):** Construção da funcionalidade de personalização de camisa com atualização dinâmica em tempo real.
4. **Deploy e Servidor Web:** Configuração de hospedagem, conexão de banco de dados em ambiente de produção e resolução de caminhos/URLs.
